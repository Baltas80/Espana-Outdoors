# España Outdoor — Licensing Policy

## Proprietary application license

España Outdoor application source code, original UX/UI, branding, original domain logic, documentation and original assets are proprietary and are not granted under an open-source license by publication of this repository.

See `LICENSE.md` for the governing proprietary license.

## Third-party materials

Third-party software, libraries, map data, imagery, elevation data and government datasets retain their own licenses and terms. They are not relicensed by España Outdoor.

Before production redistribution, the dependency/source registry must record:

- component and version;
- license;
- copyright/attribution requirement;
- source URL;
- redistribution rights;
- commercial-use constraints;
- data retention constraints;
- offline redistribution rights;
- update/freshness requirements;
- security status;
- exit strategy.

## Key obligations

- OpenStreetMap-derived data must comply with ODbL and attribution requirements.
- Official Spanish datasets must be used according to their individual reuse/licensing terms.
- Open-source libraries remain under their original licenses.
- No proprietary third-party content may be copied into the product merely because it is visible on another outdoor platform.

## Release gate

A release is blocked if a dependency or dataset has unresolved licensing, attribution or redistribution requirements.
