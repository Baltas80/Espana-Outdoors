# España Outdoor — Design System v0.1

## Dirección visual

España Outdoor debe sentirse como una mezcla de:

- cartografía profesional;
- naturaleza premium;
- herramienta de seguridad;
- producto tecnológico moderno.

Evitar estética de aplicación genérica de senderismo.

## Principios

1. El mapa es protagonista, no decoración.
2. La información crítica se lee en segundos.
3. La interfaz debe funcionar con una mano durante una actividad.
4. Seguridad y navegación tienen prioridad visual sobre funciones sociales.
5. Las fuentes y la frescura de los datos deben ser visibles.
6. Las funciones de IA se distinguen de los datos oficiales.

## Tokens iniciales

- Verde principal: `#1F6B4F`
- Fondo claro: `#F5F7F4`
- Fondo oscuro: `#0C1411`
- Radio grande: `22px`
- Radio control: `14px`
- Navegación inferior: `72px`

Los colores de peligro deben reservarse para estados de riesgo reales y no convertirse en decoración.

## Responsive

### Teléfono
Mapa + panel inferior + controles táctiles.

### Tablet
Mapa + panel lateral adaptable.

### Escritorio
Mapa principal + panel de análisis + planificación.

## Accesibilidad

Contraste adecuado, texto escalable, targets táctiles amplios, soporte de lector de pantalla y estados que no dependan únicamente del color.
